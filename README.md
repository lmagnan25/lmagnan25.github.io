# Loïc Magnan

Personal website at <https://loicmagnan.com/>.

A single static HTML page, hosted on GitHub Pages. No dependencies or build step.

## Edit

Change `index.html`, then commit and push to `main`. GitHub Pages publishes the repository root.

To preview locally, open `index.html` in a browser, or run:

```sh
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

Keep `CNAME` in the repository so future deployments retain the custom domain.
